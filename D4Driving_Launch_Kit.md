## 3. Deployment — What Goes Into Your GitHub Repo

Upload these 3 files to your existing D4Driving GitHub Pages repo (the same one serving `www.d4driving.co.uk`):

1. **index.html** — your existing homepage, now with the FREE Starter Pack button added below the hero buttons
2. **starter-pack.html** — the new standalone download page
3. **D4Driving_Starter_Pack.pdf** — the PDF itself

Once pushed, the pages will be:
- `www.d4driving.co.uk` — homepage with new button
- `www.d4driving.co.uk/starter-pack.html` — download page
- `www.d4driving.co.uk/D4Driving_Starter_Pack.pdf` — direct PDF link

---

## 4. How It All Connects

```
TikTok / Instagram bio
        ↓
starter-pack.html (download page)
        ↓
Instant PDF download (no form, no friction)
        ↓
Page includes "Book a Lesson" CTA → d4driving.co.uk/#booking
```

Every video you post with "link in bio" sends people to the download page,
which delivers the free guide and funnels them toward booking.

---

## 5. Future Option: Add Email Capture Later

If you decide to add email capture down the road, you can always add a
simple form to starter-pack.html using MailerLite's embeddable form
(no landing page or domain authentication needed — just an embed code).

This lets you collect emails alongside the free download without replacing
the current frictionless setup.
